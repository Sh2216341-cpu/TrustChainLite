# TrustChainLite

TrustChainLite is a decentralized hackathon judging system built using blockchain.

## Problem
Traditional hackathon judging lacks transparency and trust.

## Solution
This smart contract allows:
- Organizers to add judges
- Teams to register
- Judges to submit scores
- Anyone to verify results on-chain

## Features
- Transparent scoring
- Tamper-proof results
- Simple and lightweight

## Tech Stack
- Solidity
- Remix IDE
- Polygon compatible

## Demo
Contract deployed and tested using Remix VM.
Scores submitted and verified successfully.
